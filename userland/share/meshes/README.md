# ArmOS mesh collection

The OBJ files in this directory are installed in `/home/user/mesh`. All files
except the external references below are original ArmOS assets generated by
`tools/generate_demo_meshes.c` and licensed under Apache-2.0.

Installed scenes:

- `cube.obj`, `octahedron.obj`, `pyramid.obj`: basic topology checks;
- `torus.obj`: curved surface and specular-lighting test;
- `torus-knot.obj`: self-occlusion and depth-complexity test;
- `cornell-box.obj`: enclosure, clipping and future material-lighting test;
- `textured-cube.obj`: UV-bearing geometry for the future texture pipeline;
- `metallic-sphere.obj`: dense smooth normals and future material test.

The OBJ loader currently accepts texture coordinates and materials but the
educational CPU renderer ignores them. The `.mtl` files are nevertheless kept
beside their geometry so the same collection can validate the future GPU path.

## External reference scenes

The following well-known scenes are intentionally not copied into the Apache
2.0 source tree or the default 577 MiB disk image:

- Blender Suzanne;
- Stanford Bunny;
- Stanford Dragon;
- Intel/Crytek Sponza.

They remain useful manual tests once obtained under their own terms and
converted to the supported OBJ subset. Stanford scan data is restricted to
non-commercial use; Sponza is separately attributed and considerably larger;
Suzanne originates from Blender. Keeping them external preserves licensing,
attribution and the reproducibility of the normal ArmOS build.
